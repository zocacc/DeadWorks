# Assets

Os sprites `characters/mechanic_idle.png`, `mechanic_walk.png`, `mechanic_action.png`, `zombie_idle.png` e `machines/processor.png` foram gerados originalmente para DeadWorks. Cada folha de personagem tem 4 colunas × 2 linhas; o código lê as oito direções diretamente das imagens e usa quadros e efeitos curtos para as ações.

O chão e os demais objetos do protótipo são desenhados em Godot. Fontes binárias grandes selecionadas em `.gitattributes` usam Git LFS; o cache `.godot/` não entra no repositório.
